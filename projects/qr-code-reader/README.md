# QR Code Reader

Aplicação web que lê o conteúdo de um QR Code a partir de uma imagem enviada pelo usuário, direto no navegador.

## Tecnologias

- Tailwind CSS
- Alpine.js
- JavaScript

## Acesso

Faz parte do [project-hub](../../) — acesse este projeto diretamente pela pasta `projects/qr-code-reader/`.
