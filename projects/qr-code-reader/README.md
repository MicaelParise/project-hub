# QR Code Reader

Aplicação web que lê o conteúdo de um QR Code a partir de uma imagem enviada pelo usuário, decodificado direto no navegador com [jsQR](https://github.com/cozmo/jsQR) — a imagem não é enviada a nenhum servidor.

## Tecnologias

- Tailwind CSS
- Alpine.js
- jsQR
- JavaScript
