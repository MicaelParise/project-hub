# Text Translator

Tradutor de texto simples que converte conteúdo entre mais de 90 idiomas, com opções de ouvir e copiar tanto o texto original quanto a tradução.

## Tecnologias

- Tailwind CSS
- Alpine.js
- JavaScript

## Acesso

Faz parte do [project-hub](../../) — acesse este projeto diretamente pela pasta `projects/text-translator/`.
