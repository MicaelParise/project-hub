# Inactivity Detector

Monitora movimentos de mouse, teclado e toque e exibe um aviso quando o usuário fica parado por tempo demais, permitindo continuar monitorando ou encerrar a sessão.

## Tecnologias

- Tailwind CSS
- Alpine.js
- JavaScript

## Acesso

Faz parte do [project-hub](../../) — acesse este projeto diretamente pela pasta `projects/inactivity-detector/`.
