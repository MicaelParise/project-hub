# File Reader

Ferramenta simples para selecionar um arquivo de texto (.txt, .md, .html, .css ou .js) e visualizar seu conteúdo direto no navegador, sem enviar nada para nenhum servidor.

## Tecnologias

- Tailwind CSS
- Alpine.js
- JavaScript

## Acesso

Faz parte do [project-hub](../../) — acesse este projeto diretamente pela pasta `projects/file-reader/`.
