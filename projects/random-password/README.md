# Random Password

Gera senhas aleatórias fortes, combinando letras maiúsculas, minúsculas, números e símbolos, com um clique para copiar o resultado.

## Tecnologias

- Tailwind CSS
- Alpine.js
- JavaScript

## Acesso

Faz parte do [project-hub](../../) — acesse este projeto diretamente pela pasta `projects/random-password/`.
