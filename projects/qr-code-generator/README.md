# QR Code Generator

Gera QR Codes a partir de um texto ou link diretamente no navegador, com opção de escolher tamanho, cores e baixar a imagem gerada.

## Tecnologias

- Tailwind CSS
- Alpine.js
- JavaScript

## Acesso

Faz parte do [project-hub](../../) — acesse este projeto diretamente pela pasta `projects/qr-code-generator/`.
