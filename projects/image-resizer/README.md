# Image Resizer

Ferramenta que redimensiona imagens direto no navegador, permitindo ajustar largura, altura e qualidade antes de baixar o resultado, sem enviar nada para um servidor.

## Tecnologias

- Tailwind CSS
- Alpine.js
- JavaScript

## Acesso

Faz parte do [project-hub](../../) — acesse este projeto diretamente pela pasta `projects/image-resizer/`.
