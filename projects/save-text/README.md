# Save Text

Uma ferramenta simples para digitar ou colar um texto e baixá-lo como arquivo em diferentes formatos (.txt, .js, .html, .svg, .doc, .ppt).

## Tecnologias

- Tailwind CSS
- Alpine.js
- JavaScript

## Acesso

Faz parte do [project-hub](../../) — acesse este projeto diretamente pela pasta `projects/save-text/`.
