# Notes App

Bloco de notas pessoal que roda direto no navegador. Permite criar, editar e excluir notas, com tudo salvo automaticamente no `localStorage`.

## Tecnologias

- Tailwind CSS
- Alpine.js
- JavaScript

## Acesso

Faz parte do [project-hub](../../) — acesse este projeto diretamente pela pasta `projects/notes-app/`.
