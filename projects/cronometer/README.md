# Cronometer

Um cronômetro simples que mede horas, minutos, segundos e centésimos, com controles para iniciar, pausar e reiniciar a contagem.

## Tecnologias

- Tailwind CSS
- Alpine.js
- JavaScript

## Acesso

Faz parte do [project-hub](../../) — acesse este projeto diretamente pela pasta `projects/cronometer/`.
