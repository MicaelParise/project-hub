# Binary Translator

Conversor bidirecional entre texto e código binário. O texto é codificado em UTF-8, então acentos e emojis sobrevivem à ida e volta.

## Tecnologias

- Tailwind CSS
- Alpine.js
- JavaScript

## Acesso

Faz parte do [project-hub](../../) — acesse este projeto diretamente pela pasta `projects/binary-translator/`.
